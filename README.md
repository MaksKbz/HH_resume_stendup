# 📱 HH_resume_stendup — Android-приложение для автоподнятия резюме

Приложение для Android, которое **автоматически поднимает ваши резюме на hh.kz / hh.ru** —
нажимает кнопку «Поднять все резюме» (или «Поднять в поиске») за вас.

## Возможности

- 🚀 **Запустил — и оно подняло**: при открытии приложения страница «Мои резюме»
  загружается, и кнопка «Поднять» нажимается автоматически.
- 🔐 **Один вход — навсегда**: авторизация выполняется один раз во встроенном браузере
  (WebView), сессия сохраняется. Пароль нигде не хранится.
- 🔁 **Автоподнятие каждые 4 часа** в фоне (WorkManager переживает перезагрузку телефона).
- 🔗 **Своя ссылка**: можно вставить любую свою страницу с кнопкой — приложение
  откроет её под вашей авторизацией и нажмёт кнопку.
- 🔔 **Уведомления** о результате в шторке Android.
- 🛡 Платные кнопки («Продвижение», «Увеличить просмотры») специально **не** нажимаются.

## 📥 Как получить APK (без установки чего-либо на ПК)

Репозиторий настроен так, что APK собирается **автоматически в облаке GitHub**:

1. Залейте код в репозиторий (см. ниже).
2. Откройте вкладку **Actions** → дождитесь зелёной галочки у «Build Android APK».
3. Откройте завершённый запуск → внизу раздел **Artifacts** → скачайте
   **`hh-resume-standup-apk`** (это zip, внутри `app-debug.apk`).
4. Скиньте APK на телефон (Telegram «Избранное», почта, кабель — как удобно).
5. На телефоне разрешите «Установку из неизвестных источников» и установите.

### Как залить код в свой репозиторий

**Вариант А — через браузер (проще всего):**

1. Откройте репозиторий → **Add file → Upload files**.
2. Распакуйте скачанный zip проекта и перетащите **все файлы и папки**
   (включая скрытую папку `.github` — в ней настройка сборки!).
3. **Commit changes**. Сборка начнётся автоматически.

**Вариант Б — через git:**

```bash
git clone https://github.com/MaksKbz/HH_resume_stendup.git
cd HH_resume_stendup
# скопируйте сюда все файлы проекта
git add -A
git commit -m "Android app: auto-raise hh resumes"
git push origin main
```

## 📲 Как пользоваться приложением

1. **Первый запуск**: откроется страница hh.kz. Если вы не авторизованы —
   войдите как обычно (логин/пароль hh). После входа клик произойдёт сам.
2. **Дальше**: просто открываете приложение — оно само открывает «Мои резюме»
   и жмёт «Поднять».
3. **Авто-режим**: включите переключатель «Автоподнятие каждые 4 часа» —
   приложение будет делать это само в фоне, даже когда вы его не открываете.
4. **Своя страница**: вставьте свою ссылку в поле и нажмите OK — приложение
   будет открывать её и нажимать кнопку под вашей авторизацией.

## ⚠️ Важные замечания

- **Лимит hh**: поднимать резюме можно не чаще **раза в 4 часа**. Если кнопки нет
  на странице — значит, время ещё не пришло, приложение честно об этом сообщит.
- **Xiaomi / Huawei / Samsung**: для фонового режима отключите «экономию заряда»
  для этого приложения (Настройки → Батарея → Экономия заряда → выбрать
  приложение → «Без ограничений»), иначе прошивка может блокировать фоновые задачи.
- Если сессия hh истечёт (обычно раз в несколько недель), придёт уведомление
  «нужен вход» — откройте приложение и войдите ещё раз.
- Если hh изменит текст кнопки — скажите разработчику, это правится одной строчкой
  в `JsRaiser.kt`.

## 🔧 Локальная сборка (для разработчиков)
